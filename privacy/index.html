プライバシーポリシー

Calendar Sync Ebijun（以下「本ツール」）における個人情報および Google ユーザーデータの取り扱いについて定めます。

1. 本ツールの目的

本ツールは、利用者が連携した複数のGoogle Calendar間で、終日以外の予定の時間帯を非公開のブロックとして同期し、ダブルブッキングを防ぐことを目的としています。

2. 取得する情報

本ツールは、利用者がGoogleアカウントで認可した範囲において、次の情報を取得します。

  • 連携したGoogle Calendarの予定の開始時刻、終了時刻、終日かどうかの区別
  • 同期した予定と同期先ブロックの対応付けに必要なカレンダーIDおよびイベントID
  • 本ツールがGoogle Calendarへアクセスするための OAuth リフレッシュトークン

権限は、予定の読み取りと、同期先カレンダーにおける非公開ブロックの作成、更新、削除に必要な範囲に限ります。

3. 同期先へコピーしない情報

同期先のカレンダーへ書き込むのは予定の時間帯だけです。予定の件名、説明、参加者、会議URLは同期先へコピーしません。

4. 利用目的

取得した情報は、前記1の同期を実行し、その状態を維持する目的にのみ利用します。

5. 情報の保存

  • OAuth リフレッシュトークンは AWS Secrets Manager に保存します。
  • 同期に必要なイベント識別子とその対応関係は Amazon DynamoDB に保存します。

いずれも同期の実行に必要な範囲で保存します。

6. 利用しない範囲

本ツールは、取得したGoogle Calendarのデータを次の目的に利用しません。

  • 広告の配信または広告目的の利用
  • 販売または譲渡
  • 同期機能の提供と無関係な一般目的の分析
  • 第三者への提供

本ツールによる Google ユーザーデータの取り扱いは、限定的な使用に関する要件を含む Google API Services User Data Policy に従います。

7. 認可の取り消し

利用者は、Googleアカウントの「サードパーティ製アプリとサービス」の設定から、本ツールへの認可をいつでも取り消せます。取り消した後、本ツールは対象のGoogle Calendarへアクセスできなくなり、同期は停止します。
